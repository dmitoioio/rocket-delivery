# 🚀 Rocket Delivery

Курʼєрський застосунок для платформи локальних новин і бізнесу **cstllife** (м. Олика, Волинська обл.).

Кожен бізнес на cstllife (суші, піца, продукти, квіти) потребує доставки. Rocket Delivery — це один спільний застосунок, у який падають замовлення від усіх цих бізнесів і який ведуть штатні курʼєри на електроскутерах.

**Пілот:** доставка суші від закладу «Суші Мар», с. Дідичі, вул. Незалежності 19А.

## Структура репозиторію

```
rocket-delivery/
├── docs/               Проєктна документація й ADR — джерело правди
├── prototype/          Прототип із попередньої сесії (as-is, не редагувати)
├── src/                Вихідний код застосунку
│   ├── app/            Точка входу, роутинг, стан
│   ├── features/       Екрани за ролями: courier/ admin/ shared/
│   ├── lib/            Supabase-клієнт, геолокація, карти, форматери
│   └── styles/         Дизайн-система
├── public/             Статика: іконки, manifest.json, sw.js
├── supabase/           Міграції SQL, RLS-політики, Edge Functions
├── scripts/            esbuild: dev.mjs, build.mjs
└── test/               Тести
```

## Локальний запуск

```bash
nvm use                  # Node 22
npm install
cp .env.example .env     # заповнити ключі Supabase
npm run dev              # http://localhost:5173
```

Збірка: `npm run build` → `dist/`. Деплой на Netlify налаштований у [`netlify.toml`](netlify.toml).

## Технічний стек

**Vanilla JS + esbuild + PWA + Supabase** — свідомо той самий стек, що й у cstllife, щоб два застосунки злилися без переписування. Обґрунтування: [ADR-0002](docs/adr/0002-vanilla-js-esbuild.md).

Без фреймворку, без TypeScript-збірки, без рантайм-залежностей крім `@supabase/supabase-js` і `leaflet`.

## Безпека — три правила без винятків

1. **Жодна таблиця не мержиться без RLS-політики і тесту**, що анонім і чужий курʼєр її не читають. У проєкті вже був витік через RLS на приватних повідомленнях — це не гіпотетичний ризик.
2. **`service_role`-ключ ніколи не потрапляє у фронтенд.** Тільки Edge Functions.
3. **Телефон і адреса клієнта** доступні лише призначеному курʼєру і лише поки замовлення активне. Деталі: [docs/05](docs/05-roles-auth-rls.md).
