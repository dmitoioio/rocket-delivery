# Журнал архітектурних рішень (ADR)

Кожен запис фіксує **одне** рішення: що вирішили, чому, які альтернативи відкинули і чим за це платимо.

## Навіщо

Через півроку ніхто не памʼятає, чому обрали спільну базу замість API. Без ADR це рішення переглядають заново — з тими самими аргументами й тим самим результатом, тільки за тиждень.

## Правила

- Новий ADR — новий файл. **Старий ADR не редагується.**
- Якщо рішення змінилось — новий ADR, а на старому ставиться `Статус: Замінено ADR-XXXX`.
- Розділ «Чим платимо» обовʼязковий. Рішення без ціни — це не рішення, це побажання.
