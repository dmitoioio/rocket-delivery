# 08 — Дизайн-система

Перенесена з прототипу без змін. Мета — щоб реальна версія була візуально невідрізненна від того, що вже показували стейкхолдерам.

## Кольори

| Токен | Значення | Призначення |
|---|---|---|
| `--bg` | `#0B1220` | Темно-синій фон. **Не чистий чорний** — на OLED чорний дає «розмиті» межі й неприємний контраст уночі |
| `--fire` | `#FF5A3C` | «Вогонь ракети». CTA, готівка, скасування |
| `--electric` | `#45C6F0` | «Електросамокат». Посилання, онлайн-оплата, інформаційні стани |

Два акценти, не більше. Кожен додатковий колір розмиває сигнал «це головна дія».

**Семантика статусів** (кружечки на карті адмінки):

| Статус | Колір |
|---|---|
| `preparing` / `ready` | нейтральний / `--electric` |
| `courier_assigned` / `picked_up` / `on_the_way` | `--fire` |
| `delivered` | зелений |
| скасування будь-якого типу | приглушений сірий |

## Шрифти

| Шрифт | Де |
|---|---|
| **Space Grotesk** | Заголовки, коди замовлень |
| **Inter** | Основний текст |
| **JetBrains Mono** | Коди, суми, час |

Моноширинний для сум і часу — не естетика: цифри не «стрибають» при оновленні таймера кожну секунду.

## Наскрізний мотив

Пунктирна «траса» в степері статусів і у фоні — метафора маршруту скутера. Це єдиний декоративний елемент; усе інше функціональне.

## Розкладки

- **Курʼєрські екрани** — у рамці телефона на десктопі. На мобільних (≤ 600px) рамка зникає, застосунок займає весь екран.
- **Адмінка** — сайдбар на десктопі, вкладки зі свайпом на мобільному.

## Мобільні виправлення, які вже зроблені в прототипі (не зламати при переносі)

| Проблема | Рішення |
|---|---|
| iOS: `100vh` ламається при обертанні екрана й при появі адресного рядка | `100dvh` замість `100vh` |
| Десктопний сайдбар адмінки перебивав мобільну розкладку | Медіа-запити **в кінці** stylesheet — це баг каскаду, порядок має значення |
| Випадковий пінч-зум на ходу | `viewport` без можливості масштабування |

Ці три речі вже коштували часу один раз. У новій збірці вони мають бути в базовому CSS, а не «пригадатись» під час тестування.

## Свайп-навігація

Свайп вліво/вправо між вкладками — і в курʼєра (черга / активне / історія / профіль), і в адмінці (дашборд / курʼєри / готівка / аналітика / зарплата / фото / журнал).

> ⚠️ Свайп конфліктує з перетягуванням карти Leaflet. На екранах із картою обробник свайпу має ігнорувати жести, що починаються в межах контейнера карти. Баг B27.

## Компоненти, які треба винести при переносі

Прототип — один файл. При розкладанні по модулях ці елементи стають перевикористовуваними компонентами:

- `StatusStepper` — степер із пунктирною трасою
- `OrderCard` — картка замовлення (черга / активне / історія — три варіанти одного компонента)
- `CountdownTimer` — «буде готово о 19:40»
- `PhotoCapture` — обовʼязкове фото перед `delivered`
- `MoneyAmount` — сума моноширинним, з правильним відмінюванням «₴»
- `RoleGuard` — обгортка екранів за роллю
- `SwipeTabs` — вкладки зі свайпом

## Доступність — мінімум, який не можна пропустити

Курʼєр користується застосунком **на вулиці, на сонці, в рукавичках, за кермом**. Це найгірші можливі умови використання.

- Мінімальна зона натискання **48×48 px**. Не 32.
- Контраст тексту до фону ≥ 4.5:1. Перевірити `--electric` на `--bg` — блакитний на темно-синьому легко провалює поріг.
- Головна дія екрана — одна, велика, внизу (велика палець дотягується).
- Ніяких дій, що вимагають точного попадання або довгого утримання.
- Стани помилок читаються без кольору (іконка + текст, не тільки червоний).
