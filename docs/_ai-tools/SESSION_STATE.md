   була театром: код можна прочитати в інструментах розробника. Виправлено `publicOrder()` (B41).

**Висновок:** перевіряти саму перевірку. Не «код виглядає правильно», а «я змусив охорону
спрацювати й побачив це».

### ❌ Що не спрацювало і чому

- **Playwright не заповнює `.files`** для `<input capture>` у headless. Тест виглядав як баг
  застосунку. Обхід — підкласти файл через `DataTransfer` у `page.evaluate`.
- **2×2 PNG не декодується** `createImageBitmap`. Малювати кадр канвасом, не вигадувати байти.
- **`0 || 90`** — нуль falsy, інтервал генератора мовчки ставав 90. Треба `??`.
- **`fetch-depth: 1`** у GitHub Actions ламає `rev-list --count` (завжди 1). Лічильник збірки
  без `fetch-depth: 0` робив би протилежне задуманому.
- **Тести падали чотири рази поспіль не через код, а через самі тести** (регекс ловив номер
  замовлення замість PIN; клік попадав у сусідню картку). Перш ніж «лагодити» — перевір мірку.
