# Документація Rocket Delivery

Ця тека — **джерело правди** проєкту. Якщо код і документ розходяться, це баг: або код, або документ. Обидва треба привести до одного стану в тому ж PR.

## Порядок читання

**Якщо ти вперше в проєкті** — читай по порядку 01 → 02 → 03. Цього досить, щоб розуміти, що відбувається.

**Якщо ти сідаєш писати код** — обовʼязково додай [09-audit.md](09-audit.md) і [05-roles-auth-rls.md](05-roles-auth-rls.md) перед першим комітом.

**Якщо ти ухвалюєш рішення** — спершу перевір [adr/](adr/), чи його вже не ухвалили.

## Правила ведення

- Кожне нетривіальне технічне рішення → новий ADR у [adr/](adr/). Не переписувати старий ADR — створювати новий зі статусом `Superseded by ADR-XXXX` на попередньому.
- Кожен знайдений баг → рядок у [09-audit.md](09-audit.md) з ID, щоб на нього можна було послатись у PR.
- Кожне питання без відповіді → рядок в [11-open-questions.md](11-open-questions.md). Питання без власника й дедлайну не вважається зафіксованим.
